# Detailed player positions

`player_positions.json` is generated by `scripts/build_player_positions.py` from the current FPL bootstrap catalog and the GPL-3.0 EAFC26 Player Database.

The generator matches by normalized full/display name, current club, and compatible FPL position group. It emits only high-confidence matches with a clear margin over the next candidate. Players without a reliable match retain their broad FPL position at ingestion time; the generator never guesses a detailed role.

Regenerate with:

```bash
uv run python scripts/build_player_positions.py \
  --fpl-json /path/to/bootstrap-static.json \
  --eafc-csv /path/to/EAFC26-Men.csv \
  --output app/data/player_positions.json
```
